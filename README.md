# Library Management System

## Project Description

A Library Management System developed using Python. This application allows librarians to manage books and members, borrow and return books, search records, and save data using JSON files.

## Features

- Add Book
- Add Member
- View Books
- View Members
- Search Book
- Search Member
- Borrow Book
- Return Book
- Save Data
- JSON File Handling

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
